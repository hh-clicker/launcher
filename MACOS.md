# HH Clicker на macOS

Для macOS 14 и новее предусмотрены два DMG: `macos-arm64` для Apple Silicon и `macos-x64` для Intel.
Архитектуру можно посмотреть в меню Apple → «Об этом Mac»: Apple M-серия означает Apple Silicon,
Intel — версию x64. Сервисы запускаются в Linux-контейнерах Docker Desktop; Browser Agent работает на Mac.

## Установка

1. Откройте [релизы HH Clicker](https://github.com/hh-clicker/.github/releases) и выберите DMG своей архитектуры.
2. Откройте DMG, скопируйте **HH Clicker Launcher.app** в **Applications** и запускайте установленную копию.
3. Откройте настройки лаунчера и установите недостающие компоненты по предложенным кнопкам.
   Java уже входит в приложение; устанавливать JDK, Gradle или Git для готового DMG не нужно.
4. После установки Docker Desktop откройте его, завершите первоначальную настройку и дождитесь запуска Engine.
   Установка может запросить пароль администратора. Лаунчер скачивает вариант для архитектуры Mac.
5. Если Google Chrome устанавливается впервые, один раз откройте его вручную и завершите первоначальную настройку.
   Затем вернитесь в лаунчер и нажмите «Проверить снова».
6. Запустите сервисы. Первый запуск собирает контейнеры и скачивает зависимости, поэтому может занять время.
7. Откройте HH Clicker, добавьте аккаунт и войдите в HH через управляемый Chrome.
   Вход в обычном окне Chrome не заменяет вход в отдельном профиле HH Clicker.
8. Для AI-функций подключите Codex в настройках лаунчера и завершите вход по предложенному коду.

Пакет не подписан Developer ID и не нотарифицирован. Если macOS блокирует запуск,
используйте разрешение открытия конкретного приложения в «Системные настройки → Конфиденциальность и безопасность».
Отключать Gatekeeper целиком не требуется.

## Обновление и данные

Остановите сервисы, закройте лаунчер и замените приложение в **Applications** копией из нового DMG.
Настройки, профили Chrome и локальные данные лежат в `~/Library/Application Support/HH Clicker/data`;
данные PostgreSQL и авторизация Codex — в Docker volumes. Замена приложения их не удаляет.
Перед удалением Docker Desktop или его volumes сделайте резервные копии.

Не копируйте личные каталоги данных или авторизацию Codex в исходники, диагностические отчёты и release assets.
Работу поиска, откликов и диагностики страниц описывает
[общее руководство](https://github.com/hh-clicker/.github/blob/master/profile/README.md).

## Сборка из исходников

Для сборки нужны JDK 21, Node.js 24 и checkout шести репозиториев рядом друг с другом.
DMG собирается на macOS той же архитектуры, что и целевой пакет:

```bash
cd launcher
bash ./gradlew :desktopApp:packageDmg -Pnightly --no-daemon --console=plain
```

Nightly включает текущие рабочие деревья сервисов. Stable требует точные чистые checkout из
`releases/<version>/release.json`. Основной release workflow собирает обе архитектуры на отдельных runners.
