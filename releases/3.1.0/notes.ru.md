# HH Clicker 3.1.0

- Экспериментальный Windows-лаунчер на Rust: portable-версия без установщика, с отдельным хранением данных.
- Windows: исправлен запуск Docker сразу после его установки из лаунчера. Для поиска credential helper больше не требуется перезапускать лаунчер.
- Лаунчер: обновлена кнопка перехода к новой версии, включая отображение критического обновления.
- Лицензирование: добавлена MIT для кода проекта, сохранение лицензионных файлов при упаковке и уведомления сторонних компонентов в лаунчере, SPA и сервисах.

## Обновление

Поддерживается обновление с версии 2.0.0 на PostgreSQL 17. Новых миграций БД и изменений формата основной конфигурации нет. Пользовательские данные сохраняются.
