# HH Clicker 2.0.0

- Параллельная оценка сохранённых вакансий с общим прогрессом. Повторный запуск обрабатывает
  оставшиеся вакансии без оценки; сохранённые результаты не теряются при ошибке другой партии.
- Параллельный анализ рынка с сохранением состояния партий в БД, остановкой, отменой,
  продолжением и восстановлением после перезапуска backend.
- Общий предел для оценки и анализа — 4 исполнения Codex с дополнительным допуском по памяти.
  Отклики и действия HH остаются последовательными.
- Потерянные и некорректные задания оценки завершаются ошибкой; временная недоступность допускает опрос.
- Исправлена гонка сохранения вакансий и изменения стоп-листа работодателей.
- Настроены HTTP-таймауты; ожидание агента не блокирует управление другими анализами.
- Ошибки отдельных Telegram-сообщений изолированы, диагностика не раскрывает токен.
- Доступны контрольный прогон оценки без записи рейтингов и безопасные метрики операций.
- Пользовательское руководство охватывает установку, работу, аналитику и обновление.

## Обновление

Поддерживается переход с полностью запущенной 1.12.0 на PostgreSQL 17. Прежние записи
Liquibase сохраняются. Новая миграция 036 добавляет таблицу партий анализа рынка.
Перед обновлением сохраните резервную копию БД. Installer сохраняет данные и конфигурацию,
но не делает дамп PostgreSQL и не откатывает миграции.
