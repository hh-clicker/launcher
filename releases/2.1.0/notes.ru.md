# HH Clicker 2.1.0

- Linux AppImage: лаунчер и сервисы доступны в одном файле для x86_64. Проверка окружения и установка зависимостей поддерживаются на Debian 13; на других дистрибутивах лаунчер показывает инструкции. Вход в Codex, поиск вакансий, холостой проход и аналитика проверены на Linux.
- Запуск из меню Linux: AppImage можно добавить в меню приложений кнопкой в настройках; новый файл обновляет установленную копию, не затрагивая данные.
- Проверка обновлений: значок рядом с версией открывает страницу релизов и показывает обычное или критическое обновление, если установленная версия ниже поддерживаемой.
- Исправлены запуск Chrome и переключение фокуса браузера на Linux; улучшена связь Backend с Generation Agent через Docker-сеть.

## Обновление

Поддерживается обновление с версии 2.0.0 на PostgreSQL 17. Новых миграций БД и изменений формата конфигурации в этом выпуске нет. Windows-установщик сохраняет данные и настройки; AppImage заменяется целиком. Для обновления ярлыка Linux запустите новый AppImage и нажмите «Обновить» в настройках.
