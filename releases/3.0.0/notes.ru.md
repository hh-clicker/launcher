# HH Clicker 3.0.0

Критическое обновление: исправлено чтение профиля HH после изменения вёрстки. Для продолжения работы поиска на старых версиях рекомендуется обновиться.

- macOS: добавлены DMG для Apple Silicon и Intel, установка Docker Desktop, Node.js и Google Chrome из лаунчера, вход в Codex и управление сервисами. Требуется macOS 14 или новее.
- Диагностика страниц HH: проверка выбранной вкладки или всех основных страниц без отправки откликов. При ошибках чтения профиля, резюме, поиска или вакансии можно перейти к проверке непосредственно из сообщения об ошибке.
- Исправление селекторов с помощью ИИ: приложение подбирает и проверяет локальные настройки чтения страницы, если HH изменил вёрстку. Нужен подключённый Codex; проверка может занять несколько минут. Капча, ограничение доступа и мешающий диалог не считаются поломкой селекторов.
- Обновление текста резюме: на странице «Резюме» можно повторно загрузить текст с HH, сохранив настройки писем и автоматизации. При неудачной загрузке прежний текст сохраняется.
- Работа с браузером: необходимый управляемый Chrome открывается автоматически; проблемную вкладку можно показать из приложения. Улучшена обработка мешающих попапов HH и подтверждения сопроводительного письма.
- Лаунчер: PostgreSQL отображается отдельным компонентом с проверкой готовности. При недоступной БД показана причина проблемы Backend. Исправлено обновление статуса Codex после перезапуска Generation Agent.
- Улучшены совместимость шрифтов на Linux и изоляция запуска дочерних процессов на Windows.

## Обновление

Поддерживается обновление с версии 2.0.0 на PostgreSQL 17. Новых миграций БД и изменений формата основной конфигурации нет. Пользовательские данные сохраняются. Настройки селекторов хранятся отдельно; локальные ИИ-исправления применяются только к совместимой версии штатной группы селекторов.

На Linux замените AppImage; для обновления ярлыка запустите новый файл и нажмите «Обновить» в настройках. На macOS остановите сервисы, закройте лаунчер и замените приложение в Applications. DMG не подписаны Developer ID и не нотарифицированы.

После новой установки Google Chrome на любой платформе один раз откройте браузер вручную и завершите первоначальную настройку, затем возвращайтесь в лаунчер.
